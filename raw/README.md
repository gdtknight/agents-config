# Raw Sources Directory

이 디렉터리는 `agents-config` 위키가 참조하는 **불변 원본(Raw Sources)** 저장소.

- Web Clipper 문서, 외부 참고 아티클, 설계 메모, 첨부 이미지(`raw/assets/`) 배치 대상.
- LLM 에이전트는 `raw/` 파일을 읽기 전용으로만 참조하며 직접 수정·삭제하지 않음.
- 실제 운영 지식과 종합 문서는 [wiki/overview.md](../wiki/overview.md) 및 [wiki/index.md](../wiki/index.md)에서 유지보수.
